# My Record APP 1.1

当前版本为 **My Record APP 1.1**，版本号为 `1.1.0`。

在 Windows 电脑上离线管理家庭和个人的账本、资金账户、资产、借贷及投资。产品范围见 [PRD.md](PRD.md)。

## 1.1 更新

- 「记一笔」可添加、查看和移除图片附件。含附件的备份和迁移请使用 `.db`。
- 家庭和个人各有现金看板，独立显示现金合计、配置和排行榜。
- 借入和借出项目可在家庭与个人之间转移。看板将全年合计放在各月金额之前。
- 可从图标合集识别并批量导入独立图标，在账本、类目和资产中通过图片预览选用。

## 启动

1. 安装带 SQLite 的 Python 3.11 或更新版本，并将 `python` 加入 PATH。
2. 双击 `start.cmd`。浏览器会打开 `http://127.0.0.1:8765`。如果未自动打开，在浏览器中手动输入该地址。
3. 初次使用时，在首页新建账本，在「资产与借贷 → 家庭或个人 → 资金账户」新建资金账户。回到首页打开账本月历，点选某天后开始记账。
4. 关闭命令窗口或按 Ctrl+C 停止应用。再次双击即可继续使用。

图片附件、图标导入、图片识别和 Excel 功能需要运行一次 `python -m pip install -r requirements.txt`。默认数据库在 `%LOCALAPPDATA%\My Record APP\record.db`，可从「数据与设置」查看实际位置。若默认端口已占用，可以运行 `python app.py --port 8766`。临时演示可另指定数据库，如 `python app.py --db ".\demo.db" --port 8766`。

## 备份与恢复

重复运行时若原端口已占用，应用会自动选择另一个本机端口。请使用这次启动后新打开的浏览器页面，地址以命令窗口的 `My Record APP:` 输出为准。升级代码后，可关闭旧命令窗口和旧页面再运行 `start.cmd`，以保证页面和后端使用同一版本。

进入「数据与设置」，选「创建备份」并选择一个已有目录。应用会生成带日期和时间的 `.db` 快照。恢复时使用「选择备份文件」，预览后确认。应用会先在原数据目录下的 `restore-backups` 保存恢复前的账本，再替换。恢复完成后，其他已打开的标签页需要刷新。路径也可直接输入；使用系统选择器需要 Python 自带的 Tk 组件。

## 金额口径

- 收入和支出按账本统计，账户余额随资金变动更新。期初余额、账户转账、借贷本金和投资本金不计入收支。
- 投入按成本增加投资市值。部分赎回按到账金额暂调剩余市值，可按实际剩余持仓重新手动估值。全部赎回时持仓成本和市值归零。
- 投资赎回需输入本次收回成本及实际到账金额。差额为已实现盈亏，正数列为投资收益，负数列为投资亏损支出。手动估值只影响浮动盈亏。
- 借入和借出按到期日与剩余本金查看。还款或收款可只记利息，也可拆分本金和利息。

## 运行测试

在项目目录运行 `test.cmd`。需要 Node.js 22 或更新版本，浏览器测试使用本机 Microsoft Edge 或 Google Chrome。可用 `RECORD_BROWSER` 指定浏览器可执行文件路径。所有测试使用临时数据库和浏览器配置，不读取或修改正式账本。验收步骤与结果见 [ACCEPTANCE.md](ACCEPTANCE.md)。


## 家庭资产期初盘点

在首页账本卡片点击“初始化家庭资产”，或进入“资产与借贷 → 家庭资产盘点”，选择要关联的家庭账本与盘点日期。
按实物资产、投资、现金及应收款、保险、其他负债五部分添加项目，核对实时合计后点击“预览并导入”。

投资现值与保险现金价值计入总资产，剩余贷款本金与信用卡欠款计入总负债。期初盘点不生成收入支出流水。
购买总价、授信额度、购买日期、面积、贷款年限、利率和备注保留在原始盘点记录中。
每个账本提供一次期初初始化，后续余额变更从资产或账户详情操作。相同盘点重复提交不会重复创建记录。
已导入的盘点原表、账本关联、账户和资产记录随完整本地数据库一起备份和恢复。

## 表格导入导出、预算与借贷计划

Excel 支持需要运行一次 `python -m pip install -r requirements.txt`，之后可离线使用。当前开发环境的表格依赖安装在项目的 .runtime-deps 目录。
数据与设置可导出 db、xlsx 或真实 Excel 97-2003 xls，选择账本以及家庭、个人资产范围。关联账户和业务资料一并保留。筛选导出时，未选流水的净影响结转到账户期初余额，以保留账户当前余额。金额列以整数分保存，工作簿的说明页提供规则。
导入支持本应用生成的数据包，保留原表名、列名和编号关系。预览确认后替换当前全部数据，并自动保存恢复前备份。传统完整 db 备份也可继续恢复。

账单明细可切换明细或日历，在选定账本后设置月度预算。预算以支出计算，不包含转账及借贷本金。
统计分析可按周、月、年和收入、支出查看，排行默认前三项，点击查看更多展开。
借入、借出看板支持填写年化利率和 12 个月应还或应收计划，汇总各月及全年金额。实际还款或收款在借贷详情中记录。

## 当前账本与图片识别

首页“当前操作账本”保存选择，全局“记一笔”默认该账本，账本日历内仍以正在查看的账本为准。
预算设定弹窗可直接选择账本，明细页顶部也提供账本选择。

借入、借出看板的“图片识别导入”支持本机PNG、JPG、WebP表格截图。使用Windows已安装的简体中文及英文OCR语言离线识别，图像处理依赖Pillow。
表头需包含月份，各行包含名称和金额。识别结果逐行预览，可修改名称、年化利率和各月金额，也可补充或移除项目。借入本金可手动核对，借出按确认的月度金额计算。
缺少本金可以选择仅保存月度计划，该项目排除在资产和负债余额之外。借出图中工资等预计收入默认按月度计划处理。
所有空白月份须逐项填写，或明确勾选“确认为0”，之后才允许导入。导入过程原子提交，相同内容重试不会重复创建。
仅计划项目可在看板中继续编辑月度金额。

导入文件弹窗可直接选择本机.db、.xls、.xlsx文件（10MB以内），也可填写完整路径导入较大文件。支持较早导出工作簿缺少新增计划工作表的情况。

## 识别数据修复与界面对齐

新版识别会清理项目名称首尾的异常百分号和标点，排除纯符号行，合并名称、本金与月度计划完全相同的识别行。
启动时检查历史识别记录。名称首尾的异常符号会修正；纯符号名称且与正常项目的期初本金、归属、日期、利率、月度计划完全一致的重复行会移除。
修复前在数据文件旁的 recognition-repair-backups 目录生成完整备份。存在后续交易或无法确认对应关系的记录保留，以供人工核对。
借入与借出看板使用独立操作列，所有金额和表头居中。统一控件高度和标签布局，后续界面改动遵循 AGENTS.md 的对齐约定。
